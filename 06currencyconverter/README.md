# Currency Converter

A simple currency converter web application built with React that allows users to convert amounts between different currencies using live exchange rate data.

## Features

- Convert between different currencies
- Fetch exchange rates using a currency API
- Swap source and target currencies
- Select currencies from dropdown menus
- Display converted amounts rounded to two decimal places
- Responsive user interface

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Currency Exchange Rate API

## Preview

Enter an amount, select the currencies you want to convert, and click the **Convert** button to see the converted value.

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd currency-converter
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
